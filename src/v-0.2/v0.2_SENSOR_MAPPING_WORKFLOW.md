# Sensor mapping workflow (important)

The 3D plot is only scientifically meaningful if sensor IDs are correctly mapped to coordinates.

1. Run `python -m src.inspect_dataset --data-dir data --out outputs/inspection`.
2. Read `excel_workbook_report.json` to identify the workbook sheet and columns.
3. Open `sensor_xyz_template.csv`.
4. If XYZ is absent, inspect the official DWG drawing. Convert DWG to DXF with ODA File Converter, then run `src.extract_dxf_labels`.
5. Match drawing labels/measurement-point labels to the exact IDs/ports in the workbook and CSV.
6. Enter x/y/z in metres, record the coordinate source and mark review_status=`verified`.
7. In Streamlit upload the reviewed mapping CSV.

Do not assign guessed positions. If the workbook only contains a "measurement port" relation, that is not itself a spatial coordinate.
